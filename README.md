# Python for Data Analytics

Notebooks and notes for learning Python for data analytics, from Python basics to Pandas, statistics, regression and classification. Every topic is explained with simple business examples such as sales, customers, HR and operations.

All notebooks are written in Jupyter/Google Colab and can be opened and run directly.

## How to Use

1. Open a notebook from the Module folders
2. Click **Open in Colab** at the top of the notebook (or download the `.ipynb` file)
3. Run the cells one by one with `Shift + Enter`
